ROOT CAUSE of the active Swallow spell never registering (found after the Osi.AddSpell sync also
failed silently): the engine resolves/compiles a Target spell's TargetConditions and SpellRoll when
the spell is registered into a character's spellbook - through BOTH grant paths (passive
UnlockSpell boost and Osi.AddSpell). Those fields referenced the mod's own Khonsu functions
(SP_CanVore / SwallowCheck), which the engine cannot resolve because the mod's .khn thoth scripts
are not being loaded, so the compile failed and the spell was silently dropped. Zone spells were
unaffected because their khn references live in RequirementConditions/CycleConditions, which are
evaluated lazily at cast time. Evidence: game data has 49 UnlockSpell'd Target spells (35 with
SpellRoll, 44 with TargetConditions) that all register fine using only game-shipped thoth
functions; flags theories (IsSpell/Level/MemoryCost) are ruled out (34/32/34 of those 49 lack
them). The game's own ShoveCheck (CommonConditions.khn:1725) uses exactly the pattern needed.

ROOT CAUSE of the missing active Swallow spell (and of the never-appearing swallow roll, upstream
#42) found: the mod's Khonsu/thoth condition scripts were packaged at the pak root
(Scripts/thoth/helpers/*.khn), but the game only discovers thoth scripts under
Mods/<ModName>/Scripts/thoth/helpers/ (the game itself keeps them at Mods/Shared/Scripts/thoth and
Mods/Honour/Scripts/thoth). The files were therefore never loaded, so every SP_ condition function
(SP_CanVore, SwallowCheck, SP_IsActivePred, ...) was undefined at runtime - which killed the
TargetConditions/SpellRoll of all SP_Target_Swallow_* spells while spells using only engine
functions (OfferMe, SwitchToLethal) kept working. The scripts now live at
Mods/DevouringAndDigesting/Scripts/thoth/helpers/ in the source tree and in the pak.
